# Monetization Strategy for Methodwise

Given the niche nature of a TUI text base browser here some ways where we plan to monetize this project:

## 1. GitHub Sponsors
*   **GitHub Sponsors**: Zero fees from GitHub.

## 2. Homepage Ads (TUI Native)
Since Methodwise is text-based, traditional banner ads won't work. Instead, we plan to implement **"Sponsored Speed-Dials"** or **"Text Banners"**. If you are interested in advertising with us, email us at ads[at]methodwise[dot]com!

*   **How it works**:
    *   **New Tab Page**: When a user opens a new tab, instead of a blank screen, show a "Start Page".
    *   **Sponsored Links**: The Start Page lists useful, dev-focused tools (e.g., "Recommended VPN", "Cloud Hosting") as pre-filled links.
    *   **Non-Intrusive**: These are static text links, not tracking scripts or flashing banners.
    *   **Privacy-First**: We guarantee **no tracking pixels**, no unique IDs, and no data reporting on these clicks. It is exactly the same as if you typed the URL yourself.
    *   **Value**: "Sponsored by [Company]" message in the startup MOTD (Message of the Day).

*   **Example Layout**:
    ```text
    Methodwise Browser v0.1
    -----------------------
    [ Search or enter URL ]

    > Sponsored Links:
    [1] DigitalOcean ($200 Credit)
    [2] ProtonMail (Secure Email)
    [3] Cloudflare Workers (Serverless Functions)
    ```
